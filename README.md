# 思源网盘

把 `data/assets` 当成一个网盘来用：按目录浏览、按类型筛选、搜索文件名、在线看图和视频、按需下载云端资源、找回文件的历史版本，并把网盘目录保护起来不被误删。

## 入口

- **桌面端**：点击顶栏的「思源网盘」图标，打开一个独立的**页签**（可像普通文档页签一样拖动、分屏、关闭）。
- **手机端**：左上角菜单（设置列表）→「扩展」分组里的 **资源管理器 / 思源网盘 - 浏览资源**，或左侧「插件」图标。

## 功能

### 浏览与查看

- **按目录浏览** `data/assets`：面包屑可点击回退，`↑` 上一级，`⌂` 回到网盘目录；只存在于云端、本地还没有的子目录会显示为「虚拟目录」。
- **按类型筛选**：全部 / 图片 / 视频 / 音频 / PDF / Word / Excel / PPT / 文本 / 压缩 / 其他；另有「仅未下载」「有历史版本」两个快捷筛选。
- **两种视图**：列表（默认）与缩略图，随时切换。缩略图使用内核生成的图片缩略图，省流量省内存。
- **图片预览**：支持双指缩放（手机）、拖动、双击放大/还原、滚轮缩放（桌面）。
- **文件名搜索**：在本地索引与云端资源清单里按文件名/路径匹配。**搜索不会触发任何资源下载**，也不会加载资源内容。

### 网盘目录（主页目录）

- `⌂` 进入「网盘目录」，默认是 `assets`；可在面板右上角 `⚙` 或 `设置 → 集市 → 已下载 → 插件 → 思源网盘 → 设置` 里改成 `assets/同步盘` 之类的子目录，也可点「使用当前目录」一键设定。
- 删除保护、历史版本等能力都围绕这个目录生效。

### 资源按需下载

- 开启云端同步的「资源文件按需下载」后，未下载到本机的资源会在列表中显示「下载」按钮，点击即从云端补齐到本地；批量下载一次可处理多个。
- 若云端也已经没有该文件，会标记为「已丢失」，下载时会给出明确提示。

### 历史版本（查看 / 还原）

- 来自**数据快照**（不是「数据历史」）：文件有多少个内容版本会以「历史 N 版」胶囊显示在文件名下方。
- 打开文件的「🕘 历史版本」，可按时间倒序列出每个版本，**预览**（图片直接看，其它类型可下载该版本）或**还原**（会覆盖当前文件）。
- 只有 1 个内容版本的文件不显示历史版本入口。

### 文件操作

点击任意文件（图片也一样）会弹出操作菜单：

| 菜单项 | 说明 |
| --- | --- |
| 🔍 预览 | 图片直接查看，支持缩放 |
| ⬇ 下载到本地 | 未下载时出现，从云端补齐 |
| 📥 另存为 | 保存到本机（Android 会弹出系统“保存到…”对话框） |
| ↗ 用其它应用打开 | 交给系统默认应用打开（适合 PDF / Office / 视频等） |
| 📋 复制资源路径 | 复制形如 `assets/xxx.png` 的资源路径 |
| 📎 复制为引用 | 图片复制 `![文件名](assets/xxx.png)`（粘贴即显示图片）；其它类型复制 `[文件名](assets/xxx)`（可点击的资源链接） |
| 🔗 打开引用处 | 该资源被文档引用时，跳到引用它的文档 |
| 🕘 历史版本 | 有 ≥2 个内容版本时出现 |
| 🗑 删除 | 删除资源文件（可从数据快照还原） |

手机端说明：**另存为**使用系统保存对话框（与思源导出文档一致）；**分享到微信/QQ 等 IM** 暂不支持——Android 客户端没有开放系统分享接口，需要发送时请先「另存为」再从系统的文件管理/相册里分享，或用「用其它应用打开」在目标应用内转发。

### 批量操作

底部工具条支持：全选/取消、批量下载、批量复制资源路径、批量删除（二次确认）。

### 删除保护

- **思源本体和其它插件都无法删除网盘目录内的文件**，删除请求会被直接拒绝并提示；只有本插件的面板可以删除。
- 可在设置里关闭（默认开启）。
- **局限**：只拦截思源内部发起的删除请求；在系统的文件管理器里直接删除磁盘文件无法拦截。

## 配置

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 网盘目录 | `assets` | `⌂` 的目标目录，仅支持 `data/assets` 及其子目录 |
| 禁止外部删除 | 开启 | 是否阻止思源本体/其它插件删除网盘目录内的文件 |
| 视图 | 列表 | 列表 / 缩略图，随时切换 |
| 排序 | 名称升序 | 名称 / 时间 |

配置存放于 `data/storage/petal/siyuan-netdisk/`（插件私有存储，随思源同步）。

## 使用提示

- 资源索引缓存 60 秒、历史版本缓存 5 分钟；右上角 `⟳` 可强制重建。
- 未下载资源的大小、是否「已丢失」等信息按屏逐步补全，滚动或翻页会继续补全。
- 面板只处理全局资源目录 `data/assets`，不处理笔记本内部的 `assets/`。

## 注意事项

- 面板内的删除是**不可撤销**的物理删除（可事后从数据快照还原），请谨慎操作；被文档引用的资源删除后引用会失效。
- 按需下载需要内核条件：已开启云端同步、数据仓库密钥可用，并具备相应的订阅/功能特性；不满足时下载会返回错误提示。
- 网络与云端能力相关的问题（如无法下载）请先确认思源的同步配置是否正常。
